## IS 800 Steel Beam Design

The Steel Beam Design page includes a visual preliminary design interface with:
- ISMB section selection
- Steel grade selection
- Span
- Factored UDL
- Support type
- Beam visualization
- SFD / BMD / deflection visualization
- Bending and shear resistance display
- Governing utility ratio with color grading

Supported support types:
1. Simply Supported (Pin–Roller)
2. Fixed–Fixed
3. Pinned–Fixed
4. Fixed–Pinned

## Engineering disclaimer

The current Steel Beam Design calculation engine is a preliminary prototype. Before professional use, it must be validated and expanded for all applicable provisions of IS 800:2007, including section classification, bending strength, lateral-torsional buckling, shear/web checks, serviceability, load combinations, concentrated-force/web checks, and appropriate structural analysis for indeterminate support conditions.

Always verify calculations against the applicable Indian Standards, project specifications and engineering judgment.
